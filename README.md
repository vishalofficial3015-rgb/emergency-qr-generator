# 🚨 Emergency QR Code Generator

A web application that allows users to create QR codes containing their emergency contact information, medical details, and emergency service numbers.

## Features

- **Emergency Contact Information**: Store name, blood group, personal and family phone numbers
- **Medical Information**: Record medical conditions, allergies, current medicines, and emergency contact person
- **Emergency Services**: Include local ambulance and police numbers
- **QR Code Generation**: Generate scannable QR codes with all emergency information
- **Download & Print**: Save QR codes as images or print them directly
- **Share Options**: Share the website via social media, email, or copy link
- **Responsive Design**: Works on desktop, tablet, and mobile devices

## How to Use

1. Open `emergency.html` in your browser
2. Click the red emergency button to access the details form
3. Fill in your emergency information (required fields marked with *)
4. Click "Generate QR Code" to create your emergency QR code
5. Download or print the QR code for easy access in emergencies

## Files

- `emergency.html` - Landing page with emergency button and sharing options
- `index.11.html` - Main form and QR code generator page
